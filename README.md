# TechMaker 3D

**Loja virtual de produtos para a cultura Maker.**

A TechMaker 3D é uma aplicação de comércio eletrônico voltada à venda de produtos relacionados à impressão 3D, eletrônica, corte CNC e fabricação digital. O projeto busca facilitar o acesso a equipamentos, materiais e componentes para estudantes, educadores e entusiastas Maker.

🔗 **Demonstração:** https://techmaker.great-site.net/site/

## Funcionalidades

- Catálogo de produtos com categorias, filtros e pesquisa.
- Cadastro, login e autenticação de usuários.
- Carrinho de compras com gerenciamento de quantidades.
- Checkout e registro de pedidos.
- Controle de estoque.
- Integração com Google Analytics 4 e Google Tag Manager.
- Interface responsiva.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Google Analytics 4
- Google Tag Manager

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/elisananda2020-cmd/Projeto_Comercio_Eletronico.git
   ```

2. Configure um ambiente local com PHP, Apache e MySQL.
3. Importe o banco de dados.
4. Configure a conexão com o banco de dados.
5. Inicie o servidor e acesse o projeto pelo navegador.

## Observação

O projeto possui caráter demonstrativo. Atualmente, permite registrar pedidos e atualizar o estoque, mas ainda não conta com integração de pagamentos reais ou gerenciamento completo de entregas.
